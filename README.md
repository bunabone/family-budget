# תזרים משפחתי

אפליקציה פשוטה לעופר ושגית: כמה עולה לחיות החודש מול התקציב, כמה יש בכל קופה, וכמה צריך להביא מעבודה כדי לסגור את החודש.

- **ממשק:** אפליקציית רשת (PWA) סטטית, מתארחת ב-GitHub Pages, נפתחת מסך מלא מהאייקון במסך הבית.
- **נתונים:** גיליון Google בדרייב של עופר, משותף עם שגית. הגיליון הוא מקור האמת ואפשר לערוך אותו ידנית.
- **חיבור:** Google Apps Script שמפורסם כאפליקציית אינטרנט. מוגן בקוד סודי שמוזן פעם אחת בכל טלפון.
- **פירוט אשראי:** קבצי MAX וכאל נקראים בטלפון בלבד (SheetJS). לגיליון נשלחות רק העסקאות המסווגות.
- **בלי שירות בתשלום, בלי AI.**

---

## התקנה, פעם אחת (עופר, במחשב)

### 1. הגיליון והסקריפט
1. נכנסים ל-[sheets.new](https://sheets.new) ונותנים לגיליון שם, למשל "תזרים משפחתי".
2. בתפריט: **תוספים ← Apps Script**.
3. מוחקים את מה שיש בעורך, ומדביקים את כל התוכן של הקובץ [`apps-script/Code.gs`](apps-script/Code.gs). שומרים (Ctrl+S).
4. בשורה העליונה בוחרים בפונקציה **setup** ולוחצים **הפעלה**. Google יבקש הרשאה: בוחרים בחשבון, "מתקדם", "מעבר אל הפרויקט", "אישור".
5. חוזרים ללשונית של הגיליון: נוצרו הלשוניות `transactions`, `categories`, `fixed`, `income`, `rules`, `pots`, `pot_moves`, `settings` עם כל נתוני התקציב והכללים מהאפיון, וקופץ חלון עם **הקוד הסודי** (הוא שמור גם בלשונית `settings`).

### 2. פרסום ה-API
1. בעורך הסקריפט: **פריסה ← פריסה חדשה**.
2. בגלגל השיניים ליד "בחירת סוג" בוחרים **אפליקציית אינטרנט**.
3. **הפעלה בתור: אני**. **למי יש גישה: כל אחד**. (הגישה מוגנת בקוד הסודי. בלעדיו השרת לא מחזיר כלום.)
4. **פריסה**, ומעתיקים את **כתובת אפליקציית האינטרנט** (מסתיימת ב-`/exec`).

> כשמעדכנים את הקוד בעתיד: **פריסה ← ניהול פריסות ← עריכה (עיפרון) ← גרסה: גרסה חדשה ← פריסה**. כך הכתובת נשארת אותה כתובת.

### 3. שיתוף עם שגית
בגיליון: **שיתוף** ← הכתובת של שגית ← עורכת. כך היא יכולה גם לפתוח ולערוך את הגיליון ישירות. האפליקציה עצמה עובדת אצל שניכם דרך אותו API.

---

## התקנה בטלפון (כל אחד בטלפון שלו)

1. פותחים את כתובת האפליקציה ב-GitHub Pages.
2. מזינים את כתובת ה-API ואת הקוד הסודי, ובוחרים מי משתמש בטלפון.
   - קיצור: אחרי שעופר מחובר, ב**הגדרות ← קישור התקנה לטלפון השני** הוא שולח לשגית קישור שממלא את שני השדות לבד.
3. מוסיפים למסך הבית:
   - **אנדרואיד (Chrome):** תפריט ⋮ ← **התקנת אפליקציה** (או "הוספה למסך הבית").
   - **iPhone (Safari בלבד):** כפתור השיתוף (ריבוע עם חץ) ← **הוספה למסך הבית**.

## שימוש

| מסך | מה עושים |
|---|---|
| **החודש** | כמה צריך עוד כדי לסגור את החודש (ועם החיסכון), הכנסות, פס לכל קטגוריה משתנה מול התקציב והממוצע, כפתור "חודש חלש", ורשימת העסקאות. לחיצה על עסקה מאפשרת לשנות קטגוריה או אחוז משפחתי. |
| **פירוט אשראי** | בוחרים את הקבצים כפי שירדו מאתר MAX או כאל (אפשר כמה ביחד). האפליקציה מזהה כרטיס וחודש, מסננת עסקאות שכבר נשמרו, ומסווגת. רק עסקאות שלא זוהו והעברות ביט/פייבוקס מוצגות לאישור. "זכור לפעם הבאה" מוסיף כלל. על מוסך, רישוי וחו"ל מוצעת משיכה מהקופה. |
| **הזנה** | הוצאה או הכנסה ידנית: סכום, קטגוריה, הערה. |
| **קופות** | יתרה בכל קופה, "הפקדתי החודש", משיכה או הפקדה ידנית (גם ליתרת פתיחה), והוצאות גדולות קרובות עם התראה אם הקופה לא תספיק. |
| **הגדרות** | תקציב ואחוז משפחתי לכל קטגוריה, אחוז בלתי צפוי, כללי סיווג, פתיחת הגיליון. |

**ייבוא ההיסטוריה:** מעלים את `הוצאות_אשראי_מסווג.xlsx` במסך "פירוט אשראי". האפליקציה מזהה אותו ושומרת את כל העסקאות עם הסיווג הקיים, כך שהממוצעים עובדים מהיום הראשון, ובתי עסק שכבר סווגו בעבר יזוהו אוטומטית.

**יתרות פתיחה בקופות:** אם יש כבר כסף בקרן הכספית, רושמים בקופות ← "הפקדה" לכל קופה, עם ההערה "יתרת פתיחה".

**הוצאות גדולות קרובות:** ממלאים בלשונית `pots` את העמודות "יעד" ו"תאריך יעד" (בפורמט `2027-06`). תאריך שעבר מתגלגל אוטומטית לשנה הבאה.

## איך זה מחושב

- **הוצאות צפויות** = כל הקבועות (לשונית `fixed`) + לכל קטגוריה משתנה הגבוה מבין התקציב לבין מה שכבר הוצא בפועל.
- **הכנסות** = הכנסות קבועות (לשונית `income`, סוג "קבועה") + הכנסות בפועל שהוזנו לאותו חודש.
- **צריך עוד** = הוצאות צפויות פחות הכנסות. **כולל חיסכון** מוסיף את ההפקדות לקופות שלא כלולות בקבועות (חופשה ובלתי צפוי), חוץ מבחודש חלש.
- **סכום משפחתי** = סכום החיוב × אחוז משפחתי (דלק וכביש 6: 70%). רק קטגוריות מסוג "משתנה" נספרות מול התקציב. "קבוע" (כבר בקבועות) ו"מחוץ לחישוב" לא נספרות.
- **בלתי צפוי** = אחוז מההגדרות × עלות החיים (קבועות + תקציב משתנות).
- **חודש** = חודש החיוב בכרטיס.
- **כפילויות:** מזהה לכל עסקה מכרטיס + תאריך עסקה + בית עסק + סכום + חודש חיוב, כך שאותה עסקה בייצוא חודשי ובייצוא טווח נשמרת פעם אחת.

## כללי סיווג (לשונית `rules`)

הכלל הראשון שמתאים קובע, לפי "עדיפות" (מספר קטן קודם). כל העמודות שמולאו צריכות להתאים:
`בית עסק מכיל`, `הערות מכיל`, `סוג עסקה מכיל`, `ענף מכיל`, `כרטיס`, `חו"ל` (כן), `סכום מ`, `סכום עד`.
`^` בתחילת מילה פירושו "מתחיל ב" (למשל `^פז`, כדי ש"שאפז" לא ייחשב דלק). כללים שנוספים מהאפליקציה מקבלים עדיפות 5 ולכן גוברים על כללי הפתיחה. מה שאף כלל לא תפס מקבל את הקטגוריה שנבחרה בעבר לאותו בית עסק בדיוק.
